# Desafio DIO - Wireframe de Média Fidelidade

## Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio prático da DIO com o objetivo de criar um wireframe de média fidelidade para uma página única (One Page) de um produto digital.

O projeto apresenta a estrutura visual e organizacional da interface, aplicando conceitos de usabilidade, hierarquia visual e experiência do usuário estudados durante o curso.

## Objetivo

Desenvolver uma One Page capaz de apresentar de forma clara e intuitiva um produto digital, organizando as informações de maneira eficiente para facilitar a navegação e compreensão do usuário.

## Estrutura da Página

A página foi organizada em seções para facilitar a leitura e navegação do usuário:

* Header

* Apresentação do Produto
* Benefícios
* Funcionalidades
* Chamada para Ação (CTA)
* Footer

## Conceitos Aplicados

Durante o desenvolvimento foram considerados conceitos apresentados ao longo do curso, incluindo:

* Hierarquia visual
* Organização de conteúdo
* Escaneabilidade
* Consistência visual
* Clareza das informações
* Facilidade de navegação
